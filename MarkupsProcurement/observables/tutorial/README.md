# tutorial

`tutorial.Rmd` is adapted from the online tutorial that accompanies Imbens and Xu, "Comparing Experimental and Nonexperimental Methods: What Lessons Have We Learned Four Decades After LaLonde (1986)?" (arXiv:2406.00827; tutorial at https://yiqingxu.org/tutorials/lalonde/, code at https://github.com/xuyiqing/lalonde). The workflow, the functions it sources and passages of its text, including the description of the lottery data, are theirs. The data in `data/` and the application to public procurement are from my thesis.
